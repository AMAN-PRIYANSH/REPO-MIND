# Results summary

Generated by `python -m vulntrace results summary` from the committed result files. Do not edit by hand. Every number is computed by code from the files named in its row, with the same statistics code that renders the per-checkpoint results documents; `summary.json` holds the same numbers and the sha256 of every file read.

Reachability only: a verdict says whether a vulnerable function can be reached in the call graph from a `main` package, never whether the vulnerability can be exploited. Intervals are 95%; the interval type is stated per section. A paired difference is called better or worse only when its interval excludes zero.
