## Limits of this measurement

- The pool is closed: the agent can only answer with functions the release changed. Cases whose gold function is not a candidate are misses for every arm; the graph tools cannot add it (they only point to other candidates). CP5b found a candidate within 1 hop of a missing core symbol in 1 of 17 such cases.
- 7-8B local models, temperature 0, one seed: one run per configuration; run-to-run variance is not measured.
- Intervals are cluster-bootstrap 95% intervals over D4 clusters with about a hundred clusters; many comparisons are shown and none is corrected for multiplicity, so a single borderline interval is not a finding.
- Prompts and budgets were frozen before the first real run and not tuned on D4.
